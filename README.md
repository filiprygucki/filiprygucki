## Tools I build
Made at intent with Claude Code; the code is private, the ideas aren't.
- **Design system builder** — a Claude skill that applies one naming standard, semantic token tiers and AA colour rules to any Figma file.
- **Prototype builder** — turns Figma screens into clickable phone prototypes with native-feeling motion.
- **Figma design changes tracker** — shows developers what changed in Figma since the last sprint, as a changelog card and Jira tickets.

## How I work
- I start from the user's main path, then design the edge cases.
- Design and code should use the same names: tokens, components, layers.
- AI writes code with me. I decide what it builds and check what it ships.
